# Дополнительные архитектуры генеративного ИИ

ФКН НИУ ВШЭ, магистратура ИПИИ, 2 курс, модуль 1, 2026/27.
Автор курса - Андрей Ильинский.

Название архитектуры не объясняет ничего. Объясняет другое: что модель хранит,
как читает и обновляет свою память, как её обучают и во что это обходится
железу. В этих координатах курс разбирает 2 линии генеративных моделей.
Первая - модели с памятью фиксированного размера: линейное внимание,
затухание, delta rule, модели пространства состояний. Вторая - генерация
уточнением: flow matching, диффузия, диффузия для текста. Цель - уметь
разобрать архитектуру, которую видите впервые.
